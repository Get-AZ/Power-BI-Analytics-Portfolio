# Mobile Data Analysis

## Overview

This Power BI report explores mobile-device specifications and launch pricing. The workbook contains eleven report pages, including currency-specific views and bookmark-driven navigation.

## Analytical dimensions

- Company and model
- Launch year
- Processor
- RAM
- Front and back cameras
- Screen size
- Battery capacity
- Device weight
- Prices in AED, USD, INR, CNY and PKR
