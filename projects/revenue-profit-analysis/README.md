# Revenue and Profit Analysis

## Overview

This two-page Power BI report demonstrates business-performance analysis using revenue, profit, time filtering, geographic and product dimensions, and quantity measures.

## Key analytical elements

- Net revenue
- Revenue measure
- Profit measure
- Time values and time filtering
- State and product analysis
- Quantity analysis
