# Purchase Order Analysis

## Overview

This two-page Power BI report focuses on procurement and purchase-order monitoring.

## Key analytical elements

- Total purchases
- Total purchase orders
- Final and non-final purchase orders
- Total quantity
- Supplier analysis
- Buying and selling packages
- Date analysis
- Last-refresh information

## File

[`purchase-order-analysis.pbix`](purchase-order-analysis.pbix)
