# Security and data disclosure

Do not commit credentials, access tokens, private connection strings, personal data, or proprietary source datasets to this repository.

The included PBIX files were checked for obvious credential strings before publication. Power BI/Fabric report and dataset identifiers can exist inside PBIX metadata; these identifiers do not grant access to the associated account or service.

If a report is updated, repeat the privacy and credential review before committing the new binary.
