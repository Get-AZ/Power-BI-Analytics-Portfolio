## Opening the reports

1. Install Microsoft Power BI Desktop.
2. Download the required `.pbix` file from its project directory.
3. Open the file in Power BI Desktop.

GitHub does not render `.pbix` reports in the browser. The larger Purchase Order report is distributed as a versioned GitHub Release asset because it exceeds GitHub's 25 MB browser-upload limit. Screenshots can be added to each project's `screenshots` directory without changing the original report files.

## Integrity and privacy

- Original report binaries were preserved; only publication filenames were standardized.
- No passwords, access tokens, or secret values were identified in the publication audit.
- Embedded Power BI/Fabric report and dataset identifiers may remain as normal report metadata; they do not provide account access.
- SHA-256 fingerprints are recorded in [`SHA256SUMS.txt`](SHA256SUMS.txt).
